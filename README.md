# PAN Number Validation Project

## Project Overview

This project focuses on cleaning and validating a dataset containing Permanent Account Numbers (PAN) using SQL/Python. The objective is to clean the data, validate PAN numbers according to the specified format, and categorize each record as Valid or Invalid.

## Data Cleaning and Validation

The project handles missing values, duplicate PAN numbers, leading and trailing spaces, and lowercase characters. PAN numbers are converted to uppercase and validated based on length, alphabetic and numeric character requirements, repeated adjacent characters, and sequential characters.

## Analysis

The project categorizes PAN numbers into Valid and Invalid records and generates a summary showing the total records processed, total valid PANs, total invalid PANs, and total missing or incomplete PANs.

## Tools Used

SQL / Python, Excel, and data validation techniques.
